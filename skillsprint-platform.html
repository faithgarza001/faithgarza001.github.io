Core Platform Features

Everything needed to build, track, and accelerate skill growth at scale.

🎯

Gamified Sprint Engine

Learners complete time-boxed micro-courses earning XP, badges, and level-ups. Adaptive difficulty adjusts in real time based on quiz performance and completion speed.

Node.js PostgreSQL WebSockets
🤖

AI Skill Gap Analysis

ML model maps diagnostic assessment results against industry benchmarks, then recommends the optimal sprint sequence to close identified gaps in the shortest time.

Python scikit-learn REST API
📊

Real-Time Analytics Dashboard

Live metrics covering sprint completion rates, quiz scores, streaks, and time-on-task. Instructors receive at-risk learner alerts and cohort-level heat maps.

React.js Chart.js SSE
🏆

Live Leaderboards

Real-time leaderboards at individual, cohort, and organisation levels powered by WebSocket broadcasts, keeping learners motivated through friendly competition.

WebSockets Redis Node.js
🔒

Role-Based Access Control

JWT-secured multi-tenant architecture with distinct portals for Learners, Instructors, and Enterprise Admins — each with granular permissions and data isolation.

JWT Spring Security OAuth 2.0
📄

Exportable Compliance Reports

Enterprise admins can generate CSV and PDF reports on team skill progress, course completions, and certification status for HR and compliance workflows.

iText PDF Apache POI Java
